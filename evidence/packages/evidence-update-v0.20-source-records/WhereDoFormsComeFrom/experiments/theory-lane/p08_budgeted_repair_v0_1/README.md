# P08 budgeted repair pilot

The fixed incoming-record warning, periodic schedule and random schedule each receive nine repair calls per lineage; continual correction receives eighteen. Sixteen new blocks supply 256 lineages. The primary is warning minus periodic uninterrupted success through generations 15–32.

See PROTOCOL.md for the contract, DEVELOPMENT_PLAN.json and DEVELOPMENT_FREEZE.json for the pre-extraction design, development/ for all fitting results, and PREDICTION.json for the prospective decision rules. The model is fixed before fresh acquisition. Prior exposed evidence and reused code are bound in sources/ and SOURCE_REUSE.json.

The detached frozen run writes to runs/pilot_v1. Read COMPLETE.json and REPORT.md when the user requests status; FAILED.json preserves errors. No automatic scientific polling or successor is permitted.
