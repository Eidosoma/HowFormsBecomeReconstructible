17 September 2026. Development extension authorized conditional on E004's
complete confirmation, which passed. No outcome-based tuning or selection.

**Sources:** all four captured founder records from E004 blocks 1000–1015,
chosen by the first 16 IDs, not performance. These are 64 *reused* founders,
not another independent formation cohort. Fresh recipient streams use E001's
unchanged random-stream generator with public block ID `source ID + 1000000`.
Streams are paired across capacities/arms; no founder state enters a recipient.

**Change:** transmit 256, 64, or 16 float64 spatial block averages: 2048, 512,
or 128 bytes. Decode by repeating blocks over the same fixed 16×16 grid. No
post-decoding normalization. Apply the same encoding at G0 and after each of
three body-driven rewrites; a fourth fresh reader tests the last packet.
Retain all ten E001 arms and all other dynamics/timings. Shuffle the *encoded*
values at G1, preserving their multiset at each capacity. Copy preserves the
exact original encoded bytes at every boundary. All other arms transmit their
own preceding output. The original formation background enters only its named
control as an encoded packet. Public geometry/decoder are not payload bytes.

**Endpoints:** unchanged amplitude-qualified agreement with the original
founder prototype. Average recipients and founders within each of 16 blocks.
The primary is terminal own-minus-foreign agreement for each compressed size.
Use 10,000 whole-block bootstrap draws. Show pointwise 95% intervals for all
contrasts and 97.5% intervals for each of the two compressed primary tests
(Bonferroni allocation across the two sizes). Do not select one winning size.

A compressed size qualifies only if its primary 97.5% lower bound is positive,
its own-versus-foreign 95% lower bounds are positive at G1/G2/G3, G1
copy-minus-erased is readable, terminal read-off/write-off contrasts are
positive, and the full-field reference passes the corresponding 95% conjunction.
Keep every case and all failures. Compare compressed with full-field renewal
and its same-budget protected-copy arm; a positive specificity effect need
not imply lossless copying. Record each decoded incoming/outgoing field SD.

**Boundary:** this varies resolution and field amplitude together, not abstract
information capacity alone. It uses known source histories and supplied
writer/reader machinery. It is not a new-cohort confirmation of compression.

**Checks/resources:** compare factor-1 dynamics exactly with the unchanged
E001 lifecycle, test byte budgets/copy/erasure/shuffle identities, and rescore
saved outputs independently. Benchmark all three sizes using E004's disposable
