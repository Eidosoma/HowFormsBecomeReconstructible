# TT048 saved-data diagnosis v1

This analysis follows the user's instruction to diagnose TT048's wrong-task
repairs and abstention rule. All production outcomes and the main cross-arm
tables are already exposed. This is retrospective development, not a new
experiment or a prospective test. The original protocol, packets, gates and
outcomes remain unchanged. No new physical futures or serial chains are run.

Use all eight retained blocks, all 128 records and all eight input regimes.
Keep original pass/fail and all four history strata. Read only hash-verified
TT048 production evidence. The independently reviewed 4-future endpoints are
the common outcome source. Keep preservation, intended and opposite task
success, margins, and paired harms separately. Do not pool wrong-history
controls into a favorable aggregate.

## Questions and fixed diagnostic panels

1. Decompose gate rejection into nonempty input, <=5% normalized disagreement,
   anchored observed components, uniform signs within each output patch, exact
   forest/optimizer agreement at output cells (optimizer only), and no improving
   single-node move (optimizer only). Save overlapping reasons and all joint
   failure patterns; never add overlapping counts as disjoint causes.
2. Classify inferred output signs by both uniformity and the majority sign in
   each four-cell patch. Relative to the target, majority categories are
   intended, opposite, same-sign, tied and empty. Target-dependent labels are
   exclusively diagnostic and cannot enter policy selection. Cross these
   categories with actual fresh-recipient outcomes to distinguish orientation
   inference from subsequent physical expression. These are associations in
   retained data, not interventions on an individual gate or neuron.
3. Compare graph and optimizer output patterns, full packet identity, normalized
   disagreement, actual retained CPU stage times, and all paired outcome
   differences. Retain changes to planted and unplanted edges and agreement
   with the original outgoing record. That original record is a noisy reference,
   not a universally correct answer.
4. Evaluate every prelisted deterministic policy by selecting its already read
   graph/optimizer proposal or the already read unchanged input. Pairing in
   TT048 makes these one-read policy outcomes available without simulation.
   Selection receives only packet-derived structural features, not record IDs,
   regimes, masks, historical targets, original records or outcome labels.

The policy panel includes always preserve; always use the proposal; the complete
original gate with normalized disagreement thresholds
0, .025, .05, .075, .10, .15, .20, .30, 1; and the original gate with each one of
cost, anchoring, patch uniformity, forest agreement and stationarity removed.
Nonemptiness is retained in all gate relaxations. Report inapplicable graph
agreement/stationarity removals as unchanged, not independent new methods.

A second diagnostic family requires opposite nonzero patch-majority signs,
first alone, then with anchoring, then also with agreement of graph and optimizer
patch majorities. Save the consensus version both without a cost cutoff and
at .05, .10 and .20. This explicitly supplies the two-output task-family rule
that the patches should have opposite signs. It does not supply which sign
belongs at which patch, so it cannot certify the historical target. This family
is a new developmental selector, not the frozen TT048 abstention policy.

No best threshold is fitted, no cross-validation is claimed, and no automatic
successor is selected. Any apparent useful rule needs a later frozen evaluation
on new source records; four new futures on these exposed records would not make
them a prospectively fresh population.

## Summaries and checks

For every policy, method, regime and original history/pass-fail stratum, retain
record coverage, edit versus unchanged acceptance, intended/opposite success,
paired gains and harms versus preservation, record mean gains/harms, and separate
margins. Include selected-case denominators and all-case outcomes. Average
records within blocks, then available blocks equally; retain pooled results
and block values too. Empty selections have null conditional rates. No p-values
or population confidence intervals are needed for this diagnosis.

Reconstruct normalized disagreement and patch signs independently from the
retained input packets and inferred node signs. Require the .05 complete gate
to reproduce original eligibility and its selected outcomes to reproduce GA/MA
exactly. Independently recount policy outcome tables with scalar loops. Require
all selector inputs to have exactly the declared structural keys; test rejection
of hidden target/outcome fields. Check extreme threshold decisions, empty input,
and paired harmful repairs. Balanced aligned and wrong controls must receive
the same decisions for every listed selector; this directly exposes their
historical ambiguity under these feature choices.

The bounded analysis uses one numerical thread, has a 300-second deadline and
64 MiB output cap. It binds this plan and code before computing the new diagnostic
tables, preserving failures if any. No detached long job is expected. Evidence,
tables, validation and the interpretation stay under this directory; the lane
handoff records the conclusion after analysis.
