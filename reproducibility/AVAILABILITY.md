# Included material and reproduction limits

## Included

The v0.20 manuscript, evidence ledger, methods, supporting discussion and bibliography are included. Scientific wording is retained; links and figure availability are adapted. Source code, protocols and compact reports cover the local E-series, theory and Hopfield work, with selected older non-AI source and exact small records from nineteen existing evidence packages. Successes, failures and unresolved findings remain represented.

Every supplied file is at most 256 KiB. The export manifest records copied-file hashes and original paths. Paginated records avoid turning the manifest itself into a large file.

## Figures

Small measured SVG figures are included. Large PNG illustrations, raster plots and the original PDFs are omitted. The main paper uses the available SVG counterpart where possible; otherwise it retains the original full caption and an explicit omission marker.

Original plotting and extraction scripts are provided. Their input requirements differ: some work from small included tables, while others need omitted arrays or complete original ZIP packages. Original figure provenance remains unchanged. AI-generated conceptual illustrations cannot be regenerated pixel-for-pixel by running the scientific code; their small prompt/provenance files are retained where available.

## Omitted sources

Large raw arrays, large JSON/CSV outputs, archive files, duplicate job execution trees, logs, private conversation notes, old full draft copies and unrelated AI application lanes are outside this snapshot. Frozen source records retain original paths, hashes and qualifications; those paths are historical identifiers, not guarantees that every file exists in this public tree.

Some links in the original manuscript lead to this page because their target is omitted. The original and replacement target are listed in `manifests/navigation-*.json`. Evidence-package member indexes distinguish included files from large omitted members. A missing artifact must not be read as a failed scientific result or as proof that a full audit can run here.

## What the code can regenerate

The source provides the procedures used to generate simulation data and figures. The public smoke command verifies three small computational paths in isolation. Complete campaign reproduction still requires all declared predecessors, original software/numerical settings and any external source model. The cellular native checkout and some retained raw run archives are not supplied by this export. These gaps are retained explicitly from the paper's release limitations.

Run substantial computations only after reading the applicable protocol and choosing explicit resources and new output locations. Generated outputs belong in ignored directories or a separately versioned data release. No full scientific campaign, external data download, publication or background job is triggered by the review commands.
