# TT023: replacement-fill subtraction, memory feedback and writing

15 October 2026. Authorized after TT022's saved first-rewrite diagnostic. This
is a mechanism development experiment on exposed TT022 cases, designed after
their full-capture and zero-memory/no-writing outcomes were known. It is not
a new-cohort confirmation. No new scientific trajectory may precede the freeze
binding this protocol, code, sources, qualification, benchmark and resources.

Use all first injured bodies and captured incoming packets from TT022 blocks
21000000–21000003, four futures, sixteen positions and both common/informative
families. There are 32 family/future/block batches and 512 cases across families.
Do not filter current failures, replace cases, stop on outcomes or extend the
sample. Source copies and their original completion/hash receipts are retained.
Separate TT022 qualification (603210/603211, one future, one replica/message,
five updates) and benchmark (same disposable identities, two futures, four
replicas/message, 100 updates) inputs never enter the scientific summaries.

For every case, hold V0, zero ema, incoming theta, tissue parameters, injury
mask and stochastic repair/receiving environment fixed. Cross three memory
initializations with writing on/off:

| Memory | Definition | Writing on | Writing off |
| --- | --- | --- | --- |
| full | R0 = actual injured V0 | full_on, retained TT022 capture | full_off, new repair |
| subtract | Copy V0, then subtract the known resting value at fresh cells | subtract_on, new repair/read | subtract_off, new repair |
| zero | R0 = 0 everywhere | zero_on, new repair/read | zero_off, retained TT022 capture_once |

Subtraction retains the actual jitter in fresh cells and leaves the actual
body V0 unchanged. The initializer receives only V0, theta, the physical fresh
mask, resting value and a fixed mode; labels/teacher/parent states are forbidden.
All modes receive the same declared inputs. Only subtraction uses the mask to
change memory. That mask is an additional supplied resource relative to the
original rule, so no equal-information superiority or autonomous injury
recognition is claimed. The negative resting fill is native physics, not a bug.

Run exactly 1,000 unchanged native updates, with live incoming/evolving theta
reading, normal memory updating, lambda .001 and record normalization .3.
The writing switch affects theta updates only. Memory feedback remains active
in all arms. Use the existing source step without altering its equations or
the original capture API's R0=V0 requirement. The new adapter explicitly admits
the three initializers. Retain checkpoints 0, 1 and 1,000 for V, ema, R and theta.

Assay outgoing theta in the original TT022 generation-two fresh receiving
environment: zero memory, centered Gaussian birth scale .2, 1,000 updates,
no writing/feedback, and the original supplied tissue and task apparatus.
Only 256 finite float64 values (2,048 bytes per record) cross that boundary.
Use exactly TT022's SHA-256 addresses for generation-one repair and generation-
two development. This intentionally pairs counterfactuals with exposed prior
environments; it does not reserve new stochastic keys or claim fresh futures.
Native message coupling and distinct replica draws are unchanged.

Retain checked full_on and zero_off repair/read arrays without rerunning their
scientific trajectories. Every writing-off packet must stay byte-identical to
the incoming packet; bind its reused zero_off receiving read to that exact
packet, configuration, address, birth and forcing. These repeated values are
shared counterfactual controls, not independent additional assays. New work is
128 repair contexts plus 64 receiving contexts, with sixteen cases per context,
and an independent physical replay of each. Preserve all six arms' body scores
and receiving outcomes, including harms. No parental state is regenerated.

The primary descriptive contrast is informative-family next-recipient mean
recognition, subtract_on minus full_on, averaged within each block and equally
across the four blocks. Fractional credit for tied maxima remains unchanged.
Report full_on versus zero_on and subtract_on versus zero_on, all three writing
on/off contrasts, and subtract_off versus full_off and zero_off. Report both
repaired-body and fresh-recipient outcomes for each comparison, all four block
effects, four message strata, three injury-polarity strata, all 64 per-record
four-future means per family, and improved/worsened/tied records and draws.
Report the subtract-versus-full writing interaction for each endpoint. Its
recipient value equals the primary contrast by construction because all off
packets are identical; it is not separate evidence.

The directional hypothesis is that removing nominal fill improves the next
recipient, especially in negative-half and cross-boundary injury strata. No
effect threshold, p-value, confidence interval, significance gate or success-
selected policy is attached to this four-block development experiment. The
test estimates the effects of these specified interventions on exposed cases;
it cannot establish a unique general mechanism, serial durability, individual
capacity precision, biological transfer or population confirmation.

Qualification must reproduce both retained arms on excluded inputs, independently
replay all new trajectories, verify initializer selectivity, unchanged off
packets, source/body/mask custody, distinct memory states and paired random
environments, and reject corrupted states, masks, routes, scores or forbidden
label/parent inputs. Require exact serial/two-worker array equality and a full
summary/report JSON roundtrip. Native checkpoint comparisons are byte-exact;
scalar projection tolerance remains absolute 2e−13 with zero relative tolerance
and tie tolerance 1e−12. Never relax a tolerance after failure.

Benchmark two excluded blocks, both families, two futures and 100 updates with
the same reuse and independent-check paths. Forecast full elapsed time as
40 times benchmark elapsed plus 120 seconds, and output as four times benchmark
bytes plus 50% headroom. Admit forecast below eight hours, deadline max(600,
ceil(3*forecast+300)) below 24 hours, estimated run output below one GiB and at
least three GiB initially free (one GiB cap plus two GiB free reserve). Recheck
free reserve before each batch. Use two single-thread workers at nice 10 within
the shared twelve-CPU ceiling. If forecast exceeds ten minutes, detach with
stdin disconnected, unique log/PID and RUNNING/COMPLETE/FAILED receipts. Collect
one startup acknowledgment and leave unpolled until the user asks. No automatic
retry, sample extension or successor. Preserve all original TT022 artifacts.
