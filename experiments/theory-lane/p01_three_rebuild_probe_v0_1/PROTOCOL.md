The target remains strict both-cue success under the generation-32 scattered terminal assay. It is not uninterrupted success. All forecasts leave one entire block out, preserving dependence among founders, recipients, pairings and policies within that block. Scale variables using training blocks alone. Retain the prior mean-log-loss ridge logistic fit: penalty .01, unpenalized intercept, L-BFGS-B with the same tolerances. No tuning, variable selection, alternative probe-depth search or choice of model by the new results is allowed. Report every declared comparison, equal-block Brier error as primary score and log loss as secondary. Report each block and condition separately. No confirmatory p-values, binomial uncertainty treating 1,024 records as independent, or acceptance threshold is supplied by this small exposed cohort.

The fixed model set is:

1. Reproduce the two generation-1 references: current margin/pass, constant generation fraction and additive writer/pairing indicators; then add the same four mechanistic features used previously. Check held-out probabilities against the frozen reference.
2. Primary extension: the same two models at generation 3. Mechanistic features are actual-writer signed cue transfer, unsigned cue access, normalized conflict mass and body cue-difference alignment. Transfer still means the existing 64-step linear diagnostic, not native reconstruction probability.
3. Stronger condition control: the same generation-3 pair, replacing additive context with seven indicators for the eight joint pairing/writer conditions. This permits condition interactions without requiring the mechanistic features to stand in for them.
4. Short-history comparison: joint condition indicators plus current margin/pass at all three generations; compare adding the same four mechanistic features at each generation. Direct concatenation, no fitted summaries or selected contrasts.
5. Condition-only reference: predict the held-out condition's training success fraction with fixed half-count smoothing, `(successes + .5)/(n + 1)`. No probe measurements enter this model. Its inclusion tests whether any probe earns its measurement cost within this condition set.

For each feature addition, compute paired block Brier differences and count blocks with lower error, including the generation-1 negative reference. Also compare generation-3 and history augmented forecasts against the condition-only reference, and generation-3 forecasts against their generation-1 counterparts. A gain over the additive model that disappears under joint condition controls is insufficient evidence for a useful state-specific predictor. Report condition-specific error differences even if they oppose pooled results. Prediction for unseen intervention combinations is not tested by these folds.
