# Current diagnostics and history forecast comparison

TT002 is an outcome-informed follow-up to TT001 on the same exposed E041 development cohort. It asks whether earlier observations improve forecasts once a current model receives all 24 diagnostic channels. It tests a feature representation within specified learning procedures, not a causal effect of history or an RDT law.

Use the immutable TT001 development dataset and prediction files, checking their completion manifest and SHA-256 identities. Include all 32 blocks and 512 lineages, the same cutoffs 3 and 8, and both original targets. Training data include long-horizon outcomes. No native simulation, E051 observation or new confirmation population is included.

Fit two new models: logistic regression and histogram boosting on the last available value of all 24 channels. Reuse the matching 75-feature history forecasts from TT001 without refitting them. Also retain the six-channel current logistic forecast and training prevalence. All 24 channels are observed at both chosen cutoffs. The latest diagnostics include recorded prior-write quantities; they are not the complete instantaneous physical state. History adds earlier values, averages, trends and the three existing body-history summaries. Any gain may depend on the estimator and representation as well as the information available.

The new models use exactly TT001's outer block folds, inner block folds, four-setting tuning grids, loss, scaling, convergence policy, fixed seed, maximum iterations and single-class fallback. Every related lineage remains in its block. Select settings by inner mean block Brier loss only. Each new model uses 52 fitting calls per cutoff/target combination, 416 calls overall. Reuse of frozen forecasts avoids repeated training costs; the comparison does not claim equal observation/storage cost between current and history inputs.

The main descriptive contrasts are current-24 Brier loss minus history-24 loss within each learner, cutoff and target: eight contrasts. Positive values favor history. Four secondary contrasts are current-6 minus current-24 logistic loss, measuring the change from additional latest diagnostics. Report every contrast and all 24 model scores. Brier is primary descriptive loss, log loss secondary with clipping at 1e-6. Report 4096 fixed-prediction block-resampling intervals using the TT001 seed. They omit training and model-selection uncertainty and support no confirmatory test, equivalence or multiple-comparison claim. The two path endpoints cover different remaining durations and must not be directly compared as one target.

Before new native-data fits, run synthetic checks for latest-only inputs, test-label/future exclusion, disjoint blocks, missing/nonfinite rejection, constant labels and compatibility with TT001's six-channel model. Benchmark the entire new fitting workflow on synthetic arrays of the same dimensions, using excluded 0.5 placeholder reference forecasts. These placeholders are not baseline-performance evidence. One process and one numerical thread; reserve 512 MiB. Use three times the benchmark duration plus 90 seconds as the foreground forecast; a forecast above 600 seconds requires the parent detached-run policy.

Freeze this protocol, plan and executed code before scoring. Preserve failures, the selected input identities, every prediction and fitting decision, scalar score checks, software versions, timing and all outputs. Completed runs refuse overwrite. An exact numerical replay checks the same implementation only. The RDT v0.2 three-category fresh-assay candidate has a different measurement and calibration contract and is outside this comparison.
