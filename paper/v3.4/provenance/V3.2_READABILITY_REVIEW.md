# Version 3.2 readability revision

1 November 2026. The author approved all recommendations from the review of Michael Levin's 19-slide *How I Write Papers*. No v3.2 PDF existed in the private output/build locations or public version directories, so the edition remains v3.2. The [outline](V3.2_READABILITY_OUTLINE.md) was written before revising prose; the baseline (see [source availability](../SOURCE_AVAILABILITY.md)) binds the previous text.

## Reading cost and preservation

The first readability pass reduced the source text before Chapter I from 2,506 to 1,354 whitespace-delimited words. The author's terminology clarification brought that to 1,403; the later abstract revision brings it to 1,388, including the abstract, figure captions and tables: about 45% less setup before the first sustained result. This is a change in reading order, not a claim that the whole paper is 45% shorter. Overall source length remains approximately 14,000 words including references and captions because the reference tables remain in the main paper.

All scientific display equations and table cells retain their previous content. All twenty main and five supporting figures retain their assets and selection rules. The evidence ledger and supporting source are unchanged by this editorial pass. Numerical effects, uncertainty, inference units and qualification decisions are not reanalyzed or upgraded. Earlier named editions remain preserved.

The main source and its named v3.2 mirror match. Source preparation, local anchors, renumbered references and equation/figure/table preservation are checked by the versioned source validator. Both manuscripts are parsed through the publication filters to LaTeX source; this does not validate PDF pagination or visual layout.

The title remains *How Patterns Return: Memory, Repair, and Renewal in Simulated Systems*. The introduction now explicitly includes spatial, temporal and functional patterns, with biological examples beyond anatomy. “Form” refers to recognizable organization in this broad sense, not a separate class of entities or necessarily a three-dimensional shape. The text distinguishes this vocabulary from the selected patterns actually tested in simulation. The abstract uses “patterns” consistently in its opening; conceptual discussion and figure titles retain “form.”

PDF rendering and review are recorded separately in the versioned PDF validation and build records. The main PDF has now been rebuilt with the 233-word abstract; only page 1 changes visually. Pages 2–44 and the supporting PDF are unchanged. The latest manuscript edit changes only the abstract and leaves all text from the keywords onward byte-identical. Public repository export and publication remain pending. No experimental lane, source result or frozen protocol is changed by this revision.
