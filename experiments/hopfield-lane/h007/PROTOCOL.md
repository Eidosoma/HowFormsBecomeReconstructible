# H007: coherent hidden-pattern transmission screen

Frozen development screen, 12 October 2026. H006's small edge edits usually
vanished at the first rewrite. Subsequent algebra showed that those edited
packets could not be exact outputs of the fixed two-observation writer.
H005 contains persistent differences in coherent hidden patterns, but its
post-result subgroup neither qualifies the original claim nor establishes
equal current function. H007 tests feasibility of a controlled intervention
on such patterns. It does not test sixteen-generation durability.

## Sources and interventions

Use all 24 H003 development networks, seeds 13000–13023, and their sixteen
gain-4 G16 own packets per network. These 384 source checkpoints are already
exposed. Reuse the exact extracted packets and writing bodies sealed in H006's
input bundle, with the original receipts tracing them to H003. H004 is not
used. Engineering uses only the excluded source seed 12900.

Require source observations to be exact opposites at all 64 sites, to carry
the fully correct two-cue output pattern, and to have at least eight positive
and eight negative sites among hidden neurons 24–63. This one structural rule
applies to every dose. Ineligible sources remain as marked unchanged
placeholders and cannot enter comparisons.

Candidate doses swap 1, 2, 4 or 8 disjoint opposite-phase hidden-site pairs in
both source observations. Randomize the positive and negative site lists using
keys `(seed, h007, hidden_swap, founder, replica, sign)`; prefixes define nested
doses. Sites 0–23 remain fixed. Write each changed pair of observations using
the existing complete body-only writer. Compare unchanged and swapped packets.

Each changed packet is exactly obtainable from that writer and is a hidden-site
coordinate permutation of its source. Preserve the full weight histogram,
norm, nonzero count, spectrum, visible 24-by-24 block and cue/output relation.
The base matrix and all shared reader apparatus stay at their original
coordinates. Preserve gained record norm because only hidden sites move.
Base-plus-record norm need not match; retain it. Swapping k pairs changes 2k
hidden signs and 2k(64-2k) unique undirected record entries. These are larger,
structured alterations than H006's selected four edge flips; this is not an
equal-size causal comparison of the two experiments.

## Current match and pre-transmission seal

Read both variants at all four doses under the unchanged gain-4 reader,
four input sites, eight sweeps per cue and paired semantic random tapes.
Eight screening probes must all pass and match exactly in all four
task-aligned output means. A separate 64 probes validate current function and
never change membership. None of these bodies writes a packet.

Each dose's current gate requires >=64 matched packets in >=16 base networks,
mean current success >=.95 in both variants, and bootstrap intervals entirely
within [-.01,.01] for success and all four output-mean differences. Because
four doses are screened, use quantiles .0125 and .9875 (97.5% intervals) for
these equivalence checks. This controls the four candidate comparisons using
Bonferroni-adjusted one-sided tests; all observer components must pass.
Display ordinary marginal 95% intervals separately.

Seal every probe, eligibility mask, current gate and forecast before any new
replacement trial. If no dose passes, finish NO_ADMISSIBLE_CURRENT_MATCH and
generate no study replacement trials. Otherwise simulate all four doses and
all original assay candidates; failed current doses remain descriptive and
cannot qualify. Never change the current match using replacement outcomes.
Engineering forces all trials regardless of its one-block population gates
solely to exercise the pipeline; it cannot select a study dose or result.

## One replacement, eight independent trials, full controls

For each base network generate eight independent trials of exactly one new
body replacement. Erase each undirected edge with probability .5 without
rescaling. Initialize a fresh body, read the damaged packet, then create the
outgoing packet from that body only. A separate fresh, undamaged reader assays
the outgoing packet without writing it. The future gain, reader, writer,
damage law and time budget are identical across variants and doses. Damage,
births and schedules are paired across them and across record controls.
Trials are nested within base networks; they are not independent networks.

Seven arms: renewal; restored (inverse the hidden permutation at the input);
opposite-rule donor transplant with mapping [2,3,0,1]; protected copying;
cumulative-loss copying; reading blocked; writing blocked. Restoration must
equal unchanged renewal exactly in records, bodies and fresh readers. All
unchanged-renewal dose labels must give identical trajectories. Protected
copying retains each input without injury or writing. Copying requires less
computation. No new teaching or retention of old packet material enters renewal.

The primary feasibility event requires, in the same paired trial:

1. Both renewal packets equal their own distinct intended input packets exactly.
2. Both developed bodies and both fresh terminal readers pass the original
   strict output threshold (> .5 for both patches and both cues).

Thus arbitrary divergence, wrong-pattern transmission, transient body activity
or record difference alone cannot qualify. Exact self-retention, pairwise
distinctness and current/fresh-reader function are also reported separately.
Record identity concerns the complete zero-diagonal packet, not a norm or
similarity score. A passed screen establishes one-replacement feasibility,
not different durability, repair superiority or discovered competence.

## Candidate decision and reporting

Average eligible packets and trials within each nonempty network, then weight
networks equally. Freeze bootstrap seed 970007, 20,000 draws and namespace
`H007 whole-block bootstrap`. Use the same resample within a dose for every
current and replacement endpoint. Report every block and empty block.

A dose becomes a feasibility candidate only if every current and integrity
gate passes and:

- the joint functional exact-retention event has mean >=.80 (four trials in
  five on average), with one-sided lower bound >=.70;
- renewal exceeds the same event under each of read-blocked and write-blocked
  controls by >=.50, with positive one-sided lower bounds.

Use quantile .05/(4*3) for those twelve one-sided replacement bounds. These
are screen-specific feasibility requirements. They do not relax or replace
H005/H006's ten-point durability thresholds. Retain all four outcomes and
nominate the largest dose that passes the full screen. Do not enlarge the
cohort, adjust a dose or stop a trial conditionally. No passed dose means the
screen fails. No later durability run is launched by this program.

Donor, protected-copy and cumulative-loss controls are descriptive at this
single replacement; a one-step damaged copy can remain functional. Their
one-step functional performance cannot substitute for preservation of both
distinct intended records. Full-packet retention is a deliberately strong
feasibility endpoint, not a necessary condition for longer-term function.
