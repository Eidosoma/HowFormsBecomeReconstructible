# How Patterns Return

## Supporting Information — v2.4

**Working supporting information v2.4 - 28 October 2026.** Companion to *Memory, Repair, and Renewal in Simulated Systems*. Retains C.1–C.58 and five supporting figures; adds C.59–C.70 for the selected evidence through 28 October. Earlier scientific methods remain unchanged; current figure references follow the expanded main paper. P.1 distinguishes remaining prospective tests from completed multiscale development.

[Open the main paper v2.4](how-forms-become-reconstructible-v2.4.pdf). Both PDFs are prepared for the public review package. Printed methods page numbers are regenerated from this Supporting Information; the new web destinations require commit and push. No Zenodo deposit or DOI is claimed.

The **116-note evidence ledger** and extended experimental history remain separate repository documents. Evidence codes name stable notes, not independent samples or replications. D.1–D.10 refer to the historical extended evidence, not missing sections of this source.
