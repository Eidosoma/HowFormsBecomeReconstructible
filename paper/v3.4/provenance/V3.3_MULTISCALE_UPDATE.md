They are present in the pre-intake ledger and are logged separately, not silently repaired or treated as new missing multiscale sources. Every newly introduced local source link resolves. This source check does not verify public GitHub deployment or PDF annotations.

Both Markdown sources parse through Pandoc without warnings. The main contains ten tables and twenty images; the SI contains thirty tables and five images. This is a source-format check, not visual PDF inspection. The pre-intake checkpoint is explicitly eligible for Git tracking so the preservation validator can run after checkout elsewhere.

The source checks distinguish findings that the reports sometimes describe more strongly:

- “Ceiling” is rendered as a protected-reader reference. Its normalized ratio can exceed one.
- “Basins kept” is rendered as observed same-founder dependence; no proof of global basins or nonmixing is claimed.
- The 11,152-rewrite half-life bound is conditional on a model of late drift. Actual observation ends at 1024.
- “All statements hold” in AR004 and SM004 includes prespecified limitations. It does not mean either a harm-bound pass or uniformly accurate forecasts.
- NL004 supplies historical anchor values internally, while their locations, capture rule and timing remain engineered.

IA001 has a draft post hoc information-audit protocol and export inventory, not fitted decoder results. SM005 has a plan; AR005 is named as next work without a completed result in this intake. None supplies a new manuscript outcome. The pruning-duration, forecasting-prevalence and other-lane follow-ups remain untouched pending their separate review.
