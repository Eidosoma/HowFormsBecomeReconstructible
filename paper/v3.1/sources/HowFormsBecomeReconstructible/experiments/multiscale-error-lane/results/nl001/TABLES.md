# NL001 tables (development, blocks 910380–910395)

Block means (each block's mean over its 8 cases, then the mean over blocks). LR001's record of relations alone on a 64 x 64 sheet; L2 a region code (4 x 4) in the record's gauge frame, absolute or relative to the block's store; L3 a block code (16 x 16), a store or derived from the region codes. Events: none; F scattered fine flips; R coherent regional errors; B a coherent block error (absolute region codes corrupted with it); FRB all three; C3 a corrupted block store; C2 a corrupted region store; K a killed 2 x 2 square of regions.

## Registered statements

| Id | Verdict | Claim |
|---|---|---|
| D1 | HOLDS | Each scale's errors are repaired by a level at that scale. Scattered fine flips are repaired by every arm. Coherent regional errors (a region's records flipped with its boundary bonds, so the record holds no trace) are repaired by every arm with a region code and by no arm without one, a block code of up to 8 times the lane's gain included. A coherent block error is not repaired by the record alone or with a region code. |
| D2 | HOLDS | Under damage at three scales at once (fine flips, four coherent regional errors and a coherent block error), the relative three-level hierarchy repairs every scale, while the record alone, the record with a block code, and the absolute and derived hierarchies each leave the block (and without a region code the regions) wrong. |
| C1 | HOLDS | Where nothing is damaged, no level costs anything: every arm keeps the pattern, the strongest block codes included. |
| T1 | HOLDS | The region code overrides the record by its gain, whether it is right or wrong. At 0.75 and 1 times the lane's gain it repairs coherent regional errors and imposes a corrupted region store on its region; at 0.25 and 0.5 times it does neither. |
| T2 | HOLDS | An absolute block code overrides the record and the region codes by its gain, whether it is right or wrong. At up to 3 times the lane's gain it neither repairs a coherent block error that corrupted the region codes too nor imposes a corrupted block store; at 5 times and more it does both. |
| T3 | HOLDS | A block code that overrides a coherent block error restores the block's sign but not its minority regions: with the region codes corrupted, or with no region code, the block's minority regions stay wrong. |
| T4 | HOLDS | In the relative hierarchy (region codes held relative to the block's store) the block store dictates at every gain tested: a coherent block error is repaired with its minority regions, and a corrupted block store re-specifies the whole block, its minority regions included. |
| T5 | HOLDS | A block code derived from the region codes, with no store of its own, neither repairs a coherent block error that corrupted those codes nor is corrupted by a block store. |
| K1 | HOLDS | In a wound that kills every copy at the region scale and below (a 2 x 2 square of regions), a block code fills the killed regions with the block's majority: killed minority regions are restored at least 0.15 less often with a block code than without one. |
