# v2.4 exported-link audit

Every repository URL in the main and supporting PDF annotations was checked against the prepared package, public working checkout or an existing local Git object, including evidence anchors and referenced SI page numbers. This is a local package audit, not a claim of live HTTP availability. The machine-readable receipt records any failures; only a PASS supports circulation after commit and push.

The new `paper/v2.4/` destinations become public only after commit and push. Earlier source URLs retain existing paths; new source records use the versioned package. External literature URLs were not rechecked online in this packaging pass. Both PDFs offer reciprocal navigation and the [methods index](METHODS_INDEX.md) gives all 70 SI page numbers.
