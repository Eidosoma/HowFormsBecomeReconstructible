## Direction, magnitude and comparator performance

For each network compute the primary complete-task difference
`d = (pair_correct − ordinary_correct)/4`. Retain positive, negative and tied
networks, and all four task outcome classes. The one primary confirmatory test
is a **one-sided exact network sign test**: conditional on the number of
nonzero differences, calculate `Pr[Binomial(n_nonzero, 1/2) >= n_positive]`.
The null is that a fresh network is no more likely to have a positive than a
negative task difference. Ties carry no sign information but remain in every
cohort denominator and mean. No discordant networks gives p=1.

Report **DIRECTIONAL_PAIR_TASK_BENEFIT_REPLICATED** only if this p-value is at
most **0.05** and the observed mean task difference is strictly positive;
otherwise report **NO_QUALIFIED_DIRECTIONAL_PAIR_TASK_REPLICATION**. This is
directional evidence across networks, not a population-mean effect-size claim.

Hoeffding lower bound for mean d in [−1,1]. Keep a positive population-mean
qualification separate. Two-sided 95% Hoeffding intervals for absolute ordinary

covered with the sign test or other bounds. No secondary confirmatory tests,
