## One vulnerable object and its information source

Start from H095's intact, context-protected architecture. Do not combine this
test with H097/H098's edge/channel loss. The new reader component is a vector
of 48 independently learned response polarities, `c[j] in {-1,+1}`. A physical
response `z[j]` is interpreted as `y[j] = c[j] * z[j]`. This is a learned output
decoder, not a learned recurrent update rule, a replacement for the completion
family, or a general semantic interpreter.

Each engineering lineage has an independently sampled physical polarity vector
`d`, fixed across its three bodies for this first isolation. Task records,
birth states and actual parental response packets use physical coordinates.
The correctly learned decoder is `c=d`. The decoder's 48 signs occupy six
packed bytes (48 int8 bytes in the saved implementation); validity/coverage
metadata are recorded separately. At each handoff the vulnerable condition
zeros all signs and clears validity. The old decoder and its founder training
records are not supplied to the repair function. The surviving task record
stores physical associations, not a separately protected semantic decoder.

An external reference port supplies two known reference commands, all +1 and
all -1, with their actual measured physical responses `z_ref=d*y_ref`. The
repair function receives only these commands and measurements. No true task
response, hidden rule, polarity vector or old decoder is an allowed argument.
This is explicitly informative interaction: 96 measured binary values identify
48 unknown polarity bits. The sign model, meaning of the reference commands,
reference port and coordinate addresses are protected apparatus. They are
not reconstructed or claimed to emerge. The two commands are calibration
events, not two additional task observations. Charge them to every adaptive
method. Eight physical task observations per rewrite remain separate.

Without a labelled reference or retained calibration, arbitrary interpretation
is not identifiable. For any response-sign vector `f`, the worlds
`(semantic task y, polarity d)` and `(semantic task f*y, polarity f*d)`
have identical physical codewords, records, births, schedules and physical
parent emissions but different correct semantic answers. No estimator using
only that surviving packet can be guaranteed correct in both. Test this
paired-world equality explicitly. An erased decoder with no references must
return unresolved, not invent a calibration or access the evaluator's map.
