# Selected source from the originating program

This directory preserves source and selected cited documents from the older non-AI research tracks needed to inspect the paper and its model ancestry. The original `PlasticHeredity/` path hierarchy is retained beneath `upstream/`; the source is not a full copy of that project.

The public tissue and Wagner checks read the vendored native function definitions directly. Other historical runners can require external model checkouts, original absolute paths, omitted raw data or their own dependency profiles. Their inclusion makes the implementation inspectable; it does not establish that every historical launch command is portable.

Source files remain byte-identical to their recorded originals. The [export manifest](../reproducibility/export_manifest.json) identifies the selection. Existing licensing and qualifications remain in force. Current active jobs, unrelated AI lanes and the private repository history are not exported.
