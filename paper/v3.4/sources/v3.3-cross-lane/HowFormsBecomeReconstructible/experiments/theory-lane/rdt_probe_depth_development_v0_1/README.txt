Retained-cohort probe-depth development. POST HOC, not fresh confirmation.

PLAN.txt declares sources, permitted inputs, nested fitting/calibration, all
comparators, estimands, class/regime reporting and source-block uncertainty.
prepare.py exports all 319 selected native records and 638 cases, verifies B11
on every packet, and retains only the necessary cached first-writer prefix.
Large exact arrays stay in prepared/cases and run measurement directories;
prepared/SOURCES.json supplies original and exported paths and SHA-256 hashes.
No precision conversion is made. Labels are separate from numerical features.

pc_measure.py performs only the missing two native reads per depth-two branch,
using independent writer/terminal forcing and flat audit descendants. The saved
first-writer boundary already has E107's bound audit. Cached work remains charged
to each forecaster's standalone budget. Native work is 60 reads at each depth,
with 60/30/20 branches; actual new work is 40 reads plus two audits per case.

pc_fit.py uses the unchanged TT051 solvers with complete group exclusion, and
correctly scores individual futures when fitting aggregated binomial targets.
It writes held-fold predictions before aggregate scoring and separately seals
final deployment candidates. Original E107/TT051 references stay unchanged.
pc_score.py exports predictions, individual outcomes, all six weight profiles,
absolute scores, paired contrasts, calibration, probability-floor sensitivity
and source-block contributions. pc_audit.py independently replays stored model
probabilities and individual-future absolute scores.

Qualification uses a separate native stage and SYNTHETIC targets/probabilities.
Nothing in its reports is scientific forecasting evidence. Nine semantic tests
include an outer-target perturbation leakage check and a binomial aggregation
check. Full cached/native/audit/persistence paths, partial batches, nested fitting
and the complete scoring interface are qualified before a single development
launch. Failed qualifications and runs are retained; no automatic retry/resume.
qualification_v1 preserves a false memory-limit stop: getrusage retained an old
high-water value while /proc showed the current image below 53 MB. The repaired
guard uses current-image VmRSS/VmHWM and preserves the 1.5 GB ceiling. Child CPU
cost is measured relative to its value at entry. No scientific recipe changed.

Use the established PlasticHeredity virtualenv Python, PYTHONDONTWRITEBYTECODE=1,
and OMP_NUM_THREADS=OPENBLAS_NUM_THREADS=MKL_NUM_THREADS=1. Existing directories
are never overwritten. FREEZE.json binds code, plan, qualification and prepared
manifest. launch.py requires that freeze and a successful matching qualification,
then checks host CPU availability, prices the whole cohort, and starts one detached
bounded pc_run.py pipeline. Up to six numerical workers and one parent reserve
must fit the shared 12-thread ceiling. The user prefers one hour when sufficient;
the smallest justified 30-minute increment is used if more time is required,
never exceeding six hours. The job has no automatic confirmation successor.

To reproduce scoring after completion, copy its immutable fitting artifacts to
a new output directory, then invoke pc_score.main(new_directory, deadline_epoch)
in the same environment. The script refuses an existing analysis/ directory.
All numerical summaries can also be reconstructed from compact predictions,
outcomes, weights and the stated bootstrap seed. The full experiment remains
conditional on the previously exposed cohort and supplied task orientation.

No manuscript changes. The queued IA001/NL003 grouping/leakage/uncertainty review
remains required before NL003 fitting. No protected TT018 or E119/E120/E121
scientific outcomes are read. No external lane messages are sent.
