# Leads after the verified one-boundary timing result

The user asked “any leads?” after E034 closeout. This review adds descriptive
analysis of saved endpoints and packet masks; it starts no new trajectories or
successor experiment and does not change E034's failed predefined criterion.

## What the saved cases show

Under the common delayed normalized receiver and scattered injury, changing
renewal timing raises successes from 325 to 356 of 512. It recovers 53 original
failures while losing 22 original successes, a net gain of 31. Of the 156
remaining failures, **132 (84.62%)** have at least one output strongly stuck on
the same sign across opposite cues. The other classes are one fully reversed
response and 23 other failures. Stuck outputs fell from 165 to 132; 45 originally
stuck cases became correct.

The renewal body itself has 238 stuck-output cases under original timing and
156 under delayed timing. Its successes rise from 266 to 345: 101 failures
recover while 22 original successes fail. Body and terminal tests involve
different records and challenges; their different gains do not establish that
writing discarded a particular amount of information.

Both renewal timings copy an average **260.28 strong available connections**
per lineage unchanged and allow **160.23** to be refreshed. Copied connections
are **61.90% of all available connections**, pooled over the 512 lineages.
Delaying renewal changes an average 153.18 outgoing coordinates, all within
the eligible set. Thus improved body activity cannot revise the copied strong
coordinates under the current rule. This fact does not show that those copied
values are wrong; earlier experiments found that strong preservation can help.

The descriptive analysis retains all 32 blocks, all eight terminal panels,
three injuries for the own-packet arm and both body branches. E032's vector and
independent scalar output classifiers agree exactly; successes match E034
cases and all corresponding summaries. Packet counts and transition tables
also agree with separate scalar counting. Every source hash was checked before
and after. These observations identify candidates for intervention, not a
causal bottleneck.

## Recommended bounded intervention

Use the SAME delayed-renewal bodies from E034 to cross two choices:

| Capture rule | Preserve incoming strong weights | Rewrite every available weight |
| --- | --- | --- |
| Current average coactivity | Exact E034 reference | Isolate release of strong copying |
| Activity contrast between cues | Change only eligible refreshes | Combine contrast capture and release |

Reconstruct committed body states through verified replay, freeze the new
construction rules before assays, retain all 512 lineages, and test all records
under common delayed receiving settings and existing controls. Keep the same
body, injury and timing across the writing intervention. No desired output,
acquired reference packet or terminal success label may enter the writer.
This remains a final-packet intervention on existing cases; a useful result
would still require a separate serial-policy test.

The current capture can mathematically store cue-independent activity.
For a cell's transformed activities x+ and x−, define m=(x++x−)/2 and
d=(x+−x−)/2. The current neighboring-cell weight is
`(x_i+*x_j+ + x_i−*x_j−)/2 = m_i*m_j + d_i*d_j`.
This identity applies after the existing tanh transformation. A cue-contrast
capture based on `d_i*d_j` removes the common component and gives a concrete,
body-only candidate. It is not yet shown to improve transmission. Because it
also changes strength, include a magnitude-matched comparison before attributing
a benefit specifically to the cue-dependent content rather than changed strength.

The crossed copying comparison tests whether preserving strong values blocks
useful current-body updates. Full rewriting was worse in earlier serial
histories, so that history is a reason to measure the tradeoff on the SAME body,
not to assume dropping preservation will help. If contrast capture works only
when copying is released, the interaction would identify a constraint worth
testing with a local selective rule; it would not justify an unrestricted
general claim about strong weights.

Using longer settling from the first renewal remains a separate live lead:
E034 changed only one late boundary, so it did not test prevention of accumulated
decline. The proposed writing comparison can guide that next fresh serial study.
This document is a design note, not a frozen E035 protocol or a launched run.
