# TT022 saved first-rewrite diagnostic

Authorized after the completed TT022 result, on 15 October 2026. This analysis
is exploratory and specified after aggregate outcomes were inspected. It uses
the existing four exposed blocks, four futures, all sixteen positions, both
families and all seven policies. It generates no new trajectories or recipients
and does not change the frozen study or original report recovery.

Trace the first replacement through the developed body, injured body, repair
update 1, repair update 1,000 and the next developed body. Reconstruct the
original four-message scoring from saved arrays. Compare repeated and one-time
capture, checking their identical initial packet/developed body/injury and
paired receiving environments. Their memory initialization and writing differ;
this is a whole-policy comparison. Only their different outgoing packets reach
the second body, so the paired second-body difference tests the consequence of
that first repair episode under the fixed receiving environment.

For each retained row, save body recognition and margins, code projections of
memory and its bounded writer target, and incoming/outgoing packet diagnostics.
Packet diagnostics include code margin, own-code projection, projection onto
the retained-half mask, correlation with the incoming packet, RMS displacement
and displacement on fresh versus retained cells. These are geometric summaries,
not additional fresh-recipient capacity estimates. Fixed/average paths inherit
their declared native/average output, as in TT022.

Retain per-block and per-message summaries and all three injury strata: the
retained half contains only positive target cells, only negative target cells,
or both target polarities. The last stratum cuts across the task boundary.
Strata depend only on the task code and saved injury mask, not success. They
are post-result diagnostics, can be small, and are not independent population
samples. Retain improved, worsened and tied paired outcomes and the full
body/injury/next-body transition table, including already failing bodies.

Use the frozen input and output hash receipts. Recheck loaded array identities,
score arithmetic and generation-one-to-two packet routing. Reconstruct scores
by scalar summation and compare them with the frozen independent reference.
Qualify the diagnostic with known-code, tie, injury-geometry, packet-distance,
wrong-handoff and changed-score fixtures. Checks must fail on corruption; no
tolerance is changed in response to the scientific data. Scalar projections
use the existing 2e−13 absolute tolerance, zero relative tolerance; exact
scores/flags and packet bytes retain exact checks.

Report all policy/family stage scores and all geometry strata, without a
significance verdict, chosen cutoff, selected sample extension or new policy
claim. The sparse saved checkpoints cannot locate the precise failure time
between updates 1 and 1,000, and record alignment cannot replace a receiving
assay. The outcome can motivate a distinct counterfactual experiment; no new
simulation is part of this saved-data diagnostic.
