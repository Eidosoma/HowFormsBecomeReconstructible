Each experiment owns its protocol, code, tests, results, and report. Run folders
are append-only: runners refuse existing destinations, save input hashes before
simulation, and retain all declared cases. Pilot outcomes are not confirmations.
The common CPU ceiling is **12 logical CPUs**, with numerical libraries limited
to one thread per process. No GPU is required. Under the [execution policy](RUN_POLICY.md),
runs expected to exceed ten minutes are detached and checked only when the user asks.

`run_python.sh` uses the existing scientific Python environment read-only, with
bytecode disabled and caches redirected here. Set `FORMS_PYTHON` to use another
environment containing NumPy and Matplotlib. The exact environment is recorded
in each run. Source review is selective and does not imply revalidation of every
earlier result or availability of historical raw arrays.
