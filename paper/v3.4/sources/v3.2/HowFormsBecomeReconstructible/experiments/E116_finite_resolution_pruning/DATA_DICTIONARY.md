# E116 retained data

- `cases.csv`: one row per source, arm, founder, recipient, terminal draw and numerical regime. Native/mixture and sham/pulse labels remain explicit. I0/P0/I1/P1 and I1_common/P1_common contain success, continuous margins, transfer and failure classes. Success requires both cue margins strictly above .25.
- `events.csv`: full case rows with any pruning event or finite-minus-reference success event. Events are -1 harm, 0 unchanged, +1 gain. All unchanged rows remain in cases.csv.
- `erased.csv`: all 16 panel controls, four founders, four recipients and two draws per source. These are controls, not additional primary observations.
- `source_*` CSV/JSON: byte-identical copies of E112 tables and its original summary, including independent-noise writer endpoints and original individual harms.
- `writer_TASK.npz`: four F×Q body panels, each nine slots (four intact, four pruned, erased), four founders, four recipients. End states have two cues; late_ports puts the 32-observation axis after recipient. Includes incoming packets, masks, natural/effective denominator, effective directed coupling and exact reuse map.
- `capture_TASK.npz`: eight T×F×Q regimes in PLAN.json order. Contains pre-channel and transmitted packets, ordinary/contrast fields, fallback decisions, original selected coordinates and region diagnostics.
- Capture diagnostics: regions selected/outside/all, intersected with physical availability; fields are available, present_before, present_after, erased_by_grid, restored_before_grid, restored_delivered, sign_changes, fallback, exact_zero_product, near_product, mass_before, mass_after, quantization_l1, ordinary_l1, contrast_l1. near_product means 0 < abs(product) <= 1e-4 in every regime.
- `assay_TASK_rDRAW.npz`: 16 panels in plan.panels() order: four initial F×Q; eight native post-writer T×F×Q; four common zero-floor readers of floor-positive outgoing records. Each panel has the same nine slots. Contains packets, all raw endpoint fields, masks, natural/effective denominators, effective coupling and all scalar scores. Physical absence is a mask; a numerical zero is a weight.
- `*_replay_CHUNK_TASK.npz`: unique flat indices, founder/recipient contexts, floors and SHA256 state digests at every production/replayed step. Both implementations must agree before saving.
- `reuse_map` indexes the unique records in first-appearance order; `unique_flat_indices` gives that order and `unique_from_archive` marks exact archived reuse. Reuse never depends on observed outcomes.
- `summary.json`: paired whole-source pointwise 95% bootstrap intervals and all ten primary gates. Each group retains the 3×3 immediate/later event table, including unchanged cases. Continuous outcomes use native units; success and success differences are stored as fractions, plotted as percent/percentage points.
- `block_TASK.json`, `CHECKS.json`, `COMPLETE.json`: work counts, independent checks, timing and immutable output hashes. Scientific independent units are the 32 sources; no recipient or event is promoted to an independent source.
