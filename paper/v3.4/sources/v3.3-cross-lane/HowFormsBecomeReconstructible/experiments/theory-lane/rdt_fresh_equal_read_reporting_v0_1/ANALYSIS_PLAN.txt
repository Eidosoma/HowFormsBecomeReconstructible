Weights (four futures always receive one quarter of their packet's weight):

For block b, current class c and rule orientation s, let N_bcs be this study's
acquisition count and n_bcs its selected count. Selection takes one from each
orientation when both exist within a class; otherwise up to two from the one
existing orientation. The chosen identities are the smallest predeclared hash
priorities. Preserve the singleton class and all unsuccessful future outcomes.

1. balanced: original packet weight 1/(80*2*n_bc). Equal source block, equal
   current class, equal selected packet within class. Preserve its block-t
   intervals and verdict exactly; orientation balance is part of this target.
2. balanced_fail / balanced_pass: condition the original weights on class 0/1.
   These give equal block weight within each class and retain orientation balance.
3. population: expand each selected packet by a_i=N_bcs/n_bcs and divide by
   the total 5120 acquired records in the retained blocks. This also restores
   the orientation mix; substituting only one marginal class prevalence does not.
4. population_fail / population_pass: condition population weights on class,
   using its own acquired totals (868 failing and 4252 passing records).
