## Body informed averaging comparator

For every fixed-reader, zero-reset path, a separate conventional writer sees
exactly the same sequence of current body V fields. At sweep t it calculates
the arithmetic mean of V from sweeps 1 through t, then updates its own theta:

`theta = project((1 - 0.001) * theta + 0.001 * tanh(mean_V), 0.3)`.

Its starting theta is the same incoming packet. It receives no R, ema, labels,
parent record, target template or future activity. Its output does not affect
the sampled body. Compare it most directly with the native fixed-reader
writer, which uses the same activity stream; comparison with the live loop
also changes feedback and must be described that way.

Both use 1000 activity observations and a 2048-byte outgoing record per world.
Two auxiliary field buffers are allocated in every production repair call;
only the averaging sidecar uses them. Checkpoint storage is observer overhead,
not transmitted state. Record body/native-writing time and marginal averaging
time separately. Shared simulation saves computation, so the marginal writer
time alone is not a standalone cost. Report complete process runtime, peak
memory and retained/uncompressed storage. This is an information-matched,
equal-horizon comparator with a shared resource ceiling, not a claim of equal
measured CPU time or computational optimality.
