# Sign coordinates and exact donor compatibility

Write each reciprocal edge as w_ij and let G be a diagonal matrix with g_i in {−1,+1}. Set x′=Gx and w′_ij=g_i g_j w_ij. Absolute incident-weight sums are unchanged, so a normalized neighbor input transforms by g_i, including a zero-denominator row defined to give zero input. The local cubic drift and symmetric clipping are odd. Injury multiplies by a diagonal zero/one mask and therefore commutes with G. With x′ at reset and noise ξ′=Gξ, induction gives the transformed trajectory in exact arithmetic. Fixed cue values require g=+1 on input cells. Fixing all output cells preserves their arithmetic means. Floating-point implementations are checked numerically rather than assumed byte identical.

The native reset and noise are centered, spatially independent Gaussians, repeated across the two cues. Applying the same g to both cues preserves that marginal noise law and cue pairing. It does not preserve a particular path when the original noise is reused without transformation. Different transformations on contexts that originally shared randomness can also change their joint coupling; no equality of arbitrary paired comparisons follows from marginal symmetry.

For the writer, tanh(3x) transforms by g, as do cue contrast d and cue mean. Both q_ij=d_i d_j and c_ij=(x_i^+ x_j^+ + x_i^- x_j^-)/2 transform by g_i g_j. Conditions q=0 and |q|≤ε are invariant. Consequently the original and tolerance fallback branches, their availability masks, and sign-restored output transform in the same way. This does not make arbitrary edge-sign substitutions into coordinate changes.

On a surviving nonzero overlap, transforming donor signs into outgoing signs requires g_i g_j=sign(O_ij)sign(D_ij). Put g_i=(−1)^z_i to obtain a binary linear equation z_i XOR z_j=b_ij. Multiplying such constraints around a closed cycle cancels every node sign. A cycle whose right-hand product is −1 is contradictory. More generally, XORing any indexed subset of equations to obtain zero coefficients and right-hand side one certifies impossibility; this includes the declared port pin equations. Coefficient nullity still exists for an inconsistent linear system, but it is not a count of admissible alignments.

For a consistent system, let U be its homogeneous solution space. Each u in U changes backup edge signs, while kept outgoing edges remain fixed. Observable ambiguity is the dimension of these changes modulo edge changes induced by a port-fixed sign transformation of the complete hybrid. It is computed as rank([whole-hybrid switching generators, backup images of U]) minus rank(whole-hybrid switching generators). An isolated free node can therefore yield no observable ambiguity. Exhaustive small graphs compare this formula with explicit equivalence classes.

These elementary signed-graph identities are not proposed as a new RDT law. The experiment-specific question is whether the actual saved donors satisfy the exact constraints, and what the separately scored task interventions establish.
