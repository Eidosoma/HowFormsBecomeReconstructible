# Retained evidence for review

`packages/` contains small files selected from the existing frozen source-record ZIPs used by v0.20. Member bytes remain unchanged. The ZIPs themselves and oversized members are omitted under the 256 KiB limit.

The [artifact manifest](../reproducibility/artifact_manifest.json) identifies each original package. Member indexes are in `reproducibility/packages/`; copied-file hashes and omissions are in `reproducibility/manifests/`. Paths containing the former project name identify original archive members, not a second active project.

Read reported conclusions with their protocol, comparator, inference unit and qualification. A saved PASS receipt records the originating study's audit; export verification does not repeat that audit. Some original links are meaningful only in the originating workspace. Use the manuscript's evidence notes and the public index for navigation.
