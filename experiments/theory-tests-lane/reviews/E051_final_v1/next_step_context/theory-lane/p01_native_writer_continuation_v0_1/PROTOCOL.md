Status: development intervention pilot, not confirmation or a registered P01 test. The user authorized the next controlled native continuation after the failed three-rebuild forecasting check. The hypothesis and original/tolerance outcomes are known. Only the sign-restored native continuation is new. No later E051 blocks are opened.

Use the first eight already exposed blocks, 34000–34007, all four founders and four recipients, under the fully matched cue condition. There are 128 paired lineage contexts in eight block units. Start immediately before writing generation 3 from its saved end-of-reading body and mask. Verify that original and tolerance histories have identical bodies there. The two policies produced identical outgoing records through generation 2; this is the known first divergence boundary for matched cues. No lineage is selected by success, packet difference or effect size.

Branch each common body into three policies, applied at generation 3 and every remaining renewal through generation 32:

1. Original: contrast q unless q is exactly zero, then ordinary correlation c.
2. Tolerance: q unless abs(q) <= 1e-4, then c.
3. Sign-restored: sign(original weights) times abs(tolerance weights), evaluated on that branch's current body, with the same surviving-edge mask.

The control preserves tolerance magnitudes and edge support on the same body while restoring original-writer signs. An exact-zero original edge necessarily also has zero tolerance weight, so zero signs cannot delete a nonzero tolerance edge. Verify this identity in tests and at every capture. This policy uses local cue responses already available to the writer; it does not read target-rule labels. Later bodies may diverge. Consequently this estimates a total repeated-policy intervention effect, not a decomposition of the entire native dynamics into additive sign and magnitude effects.

All policies receive the original generation-specific births, damage and read noise, matched across branches. Retain the original 16-by-16 torus, reader normalization, 2,048 read steps with 1,024 settling steps, strict margin, capture rule and h32 terminal assay. Teaching is not repeated. Include the original shared erased-record terminal reference for replay validation.
