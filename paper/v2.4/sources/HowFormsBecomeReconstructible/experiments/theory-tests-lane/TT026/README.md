# TT026: writing windows during complete body repair

The user authorized this experiment after [TT025](../TT025/INTERPRETATION.md)
found a negative mean effect from each complete informative corrected rewrite.
The [protocol](PROTOCOL.md) varies corrected writing across 0, 1, 10, 100 and
1,000 updates while each body's repair continues for all 1,000 updates.
Full-capture and zero-memory full-writing controls remain. All first-episode
cases, both families, paired harms and exact packet preservation remain.

The seven variants restore the same actual injured body and incoming packet.
Each evolves its own subsequent state. Four new matched recipients assess
each outgoing record; the unchanged packet shares its verified initial assay.
Body performance remains a separate endpoint. The complete duration curve is
descriptive development on four exposed blocks, with no selected winner or
population confirmation.

Qualification and a full-duration excluded benchmark preceded production freeze.
See [execution](EXECUTION.md), [packet/body provenance](BASELINE_MANIFEST.json)
and [randomness](RANDOMNESS.json). The full schedule comprises 224 repair
batches and 896 receiving batches, all independently replayed. The run used two single-thread workers, one startup acknowledgment and no
automatic polling. The user requested the later status check.

TT026 is **complete and verified**. Production ended at **2026-10-17 12:13:12 UTC** after **44 minutes 48 seconds** on two CPUs. All 224 repair batches and 896 reader batches passed independent replay. Saved closeout passed before effect inspection, reproducing all summaries and verifying 14,336 paired receiving rows and 3,584 separate body rows. See [interpretation](INTERPRETATION.md), [full report](runs/window_v1/REPORT.md), [closeout](CLOSEOUT.json), [freeze](FREEZE.json) and [current status](CURRENT_EXECUTION.json).

The informative corrected-writing curve is **88.477%, 88.477%, 88.281%, 87.891% and 84.375%** for 0, 1, 10, 100 and 1,000 updates. Shorter writing reduces measured damage, but no tested arm improves on preservation overall. Full corrected writing has 32 paired gains and 74 harms; its mean loss is negative in all four blocks. Body performance and all controls remain separate. A [post-result next-step draft](NEXT_STEP.md) asks when a damaged incoming record can benefit from relevant body information. No successor is launched.

The user subsequently authorized the [TT027 damaged-record/body-source experiment](../TT027/README.md). It is implemented, qualified, frozen and launched with one successful startup acknowledgment. The job remains unpolled and its production outcomes uninspected; TT026 results are unchanged.

Both new workers were observed alive after launcher return. See [TT027 current status](../TT027/CURRENT_EXECUTION.json); the first finish estimate is retired.
