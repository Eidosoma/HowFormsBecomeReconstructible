# TT023: replacement fill, memory and writing

The [protocol](PROTOCOL.md) tests TT022's injury-fill lead in one controlled
repair episode. Six conditions cross full captured memory, subtraction of
nominal replacement fill, and zero memory with writing on/off. Every condition
starts with the same injured body and captured incoming packet. Physical
updates, memory feedback, paired randomness and finite receiving channel stay
fixed. The subtraction condition uses the injury mask, an additional supplied
resource that is explicitly disclosed.

All four exposed TT022 blocks, four futures, both record families and all
sixteen positions remain. This is a mechanism development experiment, with
four population blocks and no significance or fresh-confirmation verdict.
Fresh-recipient usefulness and repaired-body recognition are separate outcomes.

The original full-capture/writing and zero-memory/no-writing controls are
retained with exact source bindings. All writing-off arms inherit the identical
incoming record and reuse its checked receiving assay. New work comprises
128 repair contexts and 64 receiving contexts, each independently replayed;
the repeated control values do not constitute extra independent assays.

Qualification passes all 21 checks. The adapter reproduces both original
controls exactly; serial and two-worker execution match 96 saved array files.
Corrupted states, injury masks, record routes, labels, parental inputs and
scores are rejected. The full summary/report JSON roundtrip passes.

The [completed experiment](INTERPRETATION.md) supports the fill-removal
intervention on these cases. Informative-record next-recipient recognition
rises from **61.328% to 87.891%**, a **26.5625-point** gain, positive in all four
blocks. Zero-memory writing gives 81.641%; preserving the incoming packet
still gives 89.844%. Corrected writing improves 39 record means and worsens two
relative to full capture. Injury-stratum harms and all six arms remain in the
report. Common-record gain is smaller at 3.516 points.

This establishes an intervention effect for one repair episode on exposed
cases, with the injury mask supplied. Serial durability remains open. Body and
recipient scores remain distinct; corrected informative writing has a higher
recipient score but a lower body score than zero-memory writing.
