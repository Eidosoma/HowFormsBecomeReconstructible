## Recovery information and actual inheritance

One independently sampled 48-sign polarity vector per base network is shared
across its related births, own/donor sources and matched methods. It stays
fixed across G0/G1/G2. Only its learned output decoder is made vulnerable.
Physical task records and parent emissions use the encoded coordinates.
The semantic interpretation is supplied by the learned decoder after reading;
decoder availability does not change physical task transmission or recurrence.

The learner receives two labelled reference commands (all +1, all -1), their
actual physical measurements and coverage flags. Ninety-six measured binary
values identify 48 unknown signs. The sign model, coordinate addresses,
reference meanings and reference port remain protected apparatus. No true task
answer, hidden polarity or old decoder is supplied to the repair function.
Eight actual parent task responses per rewrite are a separate information
budget. Native fits use the same supplied completion family. Copied records
are complete, and decoder storage and reference interaction are counted.

Use all H095 protected inheritance routes and controls: independent rewriting,
independent copying, four independent native methods, and same-parent copying
plus four native fits from the rewriting parent's actual packet. Retain both
parent policies, both neural recipient readers, own/donor/erased task-record
controls and both task panels. Each independent lineage takes two actual
handoffs. Same-parent controls are freshly acquired at G1/G2 from the declared
rewriting parent. Native controls have their separate substrate and ceiling.

Each physical acquisition is interpreted under three decoder conditions:
retained learned codebook; erased codebook with no references (unresolved);
erased codebook repaired from the two reference measurements. All methods get
identical matched reference tapes in the repair condition. The retained
whole-state copy remains a separate ceiling. No-reference abstentions are not
incorrect binary guesses and must be reported as unresolved coverage. H099's
paired-world ambiguity argument applies: arbitrary semantics cannot be
recovered from physical associations alone. References supply the missing
information explicitly; their benefit is not evidence of reconstruction
superiority or a discovery that the elementary calibration formula works.

## Eight separate finite-cohort decisions

Primary G0 uses the pair reader; G1/G2 use ordinary recipients of pair-assisted
parents. A query requires >=44/48 correct bits and all signs resolved; a task
requires all eight panel queries. Primary task source is own reconstruction
with reference-repaired decoder. The 128 task trials are not 128 independent
networks. No population-confidence or efficiency qualification is inferred.

1. Calibration recovery: every G1/G2 repaired decoder recovers all 48 signs,
   agrees with retained calibration, and no-reference decoders remain entirely
   unresolved. This is a prerequisite check, not a task-retention result.
2. G0 unseen acquisition: >=75% tasks and >=25 percentage-point gaps over both
   donor and erased task records.
3. G2 unseen retention: G0 passes and G2 meets the same capability/source gaps.
4. G2 taught retention: >=75% tasks and the same source gaps on taught queries.
5. Reference-observation benefit: for both independent neural routes at G2,
   repair has positive task gains minus losses and nonnegative query net over
   its own erased/no-reference condition. Report the unresolved-coverage change.
6. Benefit over observation-limited copying: primary repaired reconstruction
   has positive task net and nonnegative query net against both independent
   and same-parent copies with erased/no-reference decoders. Explicitly label
   this information-unequal comparison; it is not superiority over copying.
7. Benefit beyond equally informed adaptive copying: the same requirements
   against both independent and same-parent copies with repaired decoders.
8. Benefit beyond native controls: the same requirements against all eight
   independent/same-parent native controls with repaired decoders.

Use paired outcomes on the same network/birth/query. A tie fails a strict
benefit gate. Keep retained-copy contrasts and parent-policy contrasts visible
as diagnostics. Never combine gates 5/6 with gates 7/8 or with H033's unrelated
historical verdicts. Retain taught/unseen and acquisition/inheritance separately.
