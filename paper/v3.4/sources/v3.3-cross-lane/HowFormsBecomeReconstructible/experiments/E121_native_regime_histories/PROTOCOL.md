## Two explicit once-only interventions

From each regime's first recovery output preserve:

1. I: intact record.
2. PF: remove nonzero restored connections whose incoming value was exactly
   zero **and** that regime's fallback was used.
3. PR: remove nonzero restored connections whose incoming value was exactly
   zero, **regardless of capture route**.
4. E: the erased source branch, with its actual written successor.

PF may be empty under independent noise. Preserve zero selections as no-ops,
with actual counts and outcomes. PR is frozen before scientific formation and
uses the same route-independent definition in every regime. It uses the
incoming/output boundary records, not future scores, a target label or
performance optimization. It is an experimental intervention, not a claimed
autonomous policy. No promise of an immediate benefit is built into selection.
PR equals PF wherever all restored edges used fallback; record overlap exactly.

Follow I/PF/PR/E through one actual writer under their own regime. No re-pruning.
Fresh assessments at generations 0 and 1 use two independent draws matched
across policies/regimes/horizons and independent of lineage dynamics. Common
readers use matched cue noise for a record-only comparison; native readers use
the respective regime's noise for whole-formulation usefulness. Birth/reset
remains shared in both. Assessments have 24-cell injury and never write back.

## Inference and useful-performance safeguards

Primary is **PR** in pooled independent-noise tolerant mixture histories under
the common reader: immediate benefit, later cost, all four absolute success
lower 95% bounds > 50%, and each endpoint's paired difference from matched-exact
PR lower bound > −5 points. Also require first committed acquired success under
the native reader and all four native-reader reconstruction lower bounds > 50%.
These extra requirements make the first two native stages reviewable rather
than rescuing a reversal observed only in nonfunctional records. No cases are
dropped when these gates fail. PF is an explicit secondary intervention; it
cannot replace a failed PR primary, and an empty PF is not a negative test of
an applied pruning intervention.

Equal within-source weighting, 32 independent blocks, 10,000 paired whole-source
bootstrap resamples. The conjunction uses pointwise 95% component intervals;
report all four regime effects and both interventions, native and separate
histories, signed margins/transfer, normalized coupling, re-isolation, ordinary
versus contrast captures and every individual harm. Regime-specific selection
can differ: retention compares complete histories and the same semantic policy,
not identical edge coordinates. No result is inferred from E051's success rate.
