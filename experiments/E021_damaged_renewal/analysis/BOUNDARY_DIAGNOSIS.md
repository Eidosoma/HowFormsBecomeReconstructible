# E021 saved-boundary diagnosis

20 September 2026. Authorized after E021's failed damaged-renewal result.
This is a post-hoc descriptive analysis of the existing cohort, not a new
experiment, a new qualification gate or a change to the frozen protocol.

Use every saved boundary in all 32 blocks and all six chains. Keep generation
2 despite the absence of a terminal assay there. Never substitute body-state
outputs for fresh-body function. No simulation, parameter selection, mask
rejection or new assay is part of this analysis.

Measure, before inspecting the new diagnostic results:

- Last-32-update and instantaneous read-end correctness under both cues,
  individual-cue output margins and error types; link the same lineages to
  existing intact own-record terminal assays at generations 1 and 3.
- Reconstruct every immediate packet directly from saved activity and check
  serial reuse, physical zeros, copying and cumulative edge erasure.
- Incoming, effective-reading and outgoing record magnitudes, zero fractions,
  sign changes, and magnitudes on previously erased coordinates that are
  physically available again. Report cue opposition and activity magnitude
  in the body. These are descriptive diagnostics, not functional scores.
- Distinguish absent paths from weak paths. For each record use reciprocal
  edges with exactly nonzero magnitude to find reachability from the four
  input cells to all eight output cells. Also calculate each output cell's
  widest-path capacity: the largest minimum absolute edge weight among paths
  from any input cell. Report the weakest of these eight capacities. This
  needs no arbitrary weight cutoff and ignores edge signs, so connectivity
  and path strength alone cannot establish correct routing.
- Compare the physical surviving lattice, damaged rewriting, intact rewriting,
  protected copying and copying with matched accumulated edge erasures.
  Keep blocked conditions in tables and raw diagnostic rows.
- Preserve lineage identities in read-end-to-assay and generation-to-generation
  transitions. Counts and means describe the full retained cohort; no new
  inferential claim or bootstrap threshold is introduced.

Verify the original completion/audit identity, frozen inputs and hashes of
all consumed data. Check saved terminal scores against the original CSV and
block summaries. Exercise graph calculations on known paths and compare
widest-path reachability with an independent threshold flood fill. Save
per-lineage rows, summary, report, figure and provenance in a new directory.
Original runs remain unchanged.

Benchmark the analysis on the existing excluded block 900021 before the
scientific cohort. Forecast `2.5 * benchmark_variable_seconds * 128 + 60`,
where variable work includes input verification, archive analysis and CSV
reading; 128 is the cohort/benchmark lineage ratio. Plotting and report

thread. If the forecast exceeds ten minutes, detach under RUN_POLICY.md;
