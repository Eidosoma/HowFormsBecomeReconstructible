# H007: coherent hidden-pattern transmission

H006's small edge alterations generally vanished at the first rewrite. H007
changes an entire hidden activity pattern and re-encodes it with the same
writer. The [protocol](PROTOCOL.md) freezes a one-replacement feasibility
screen before a separate durability study can be considered.

The development screen completed on **12 October 2026** in **11 minutes
22 seconds**. **All four doses passed every frozen gate**, so the declared
largest-passing-dose rule nominates **eight hidden-neuron pairs**. All ten
scientific fixtures and **7,011 audit checks** passed. All four checksum
manifests and the launch freeze verified; the finished figure was inspected.

Every dose has matches in all 24 networks. These are equal-network means;
each dose has its own current-matched cohort, so differences between rows are
not a controlled dose-response estimate. For dose eight, the adjusted current
success-difference interval is **[-0.16, 0.56] percentage points**, and all
four output intervals also lie inside the frozen ±1-point bounds. This is
finite, cohort-level equivalence, not equality for every individual packet.

After the single damaged replacement, the selected dose's renewal packets
remain distinct in every matched trial; exact self-retention is **98.86%
unchanged and 98.89% swapped**. The stronger joint event additionally requires
both rebuilt bodies and both fresh readers to be functional, giving **94.15%**.
Blocking either reading or writing reduces that event to zero. Exact
restoration reproduces unchanged renewal in records, bodies and readers.
Protected copying retains both intended packets exactly; damaged copying
also supports high one-step function despite lacking exact packet retention.
No superiority to copying was tested or established.

H007 resolves the narrow feasibility concern that a coherent hidden-pattern
intervention might immediately disappear or spoil current function. It does
not establish different long-term durability. The separately frozen follow-up
[H008](../h008/README.md) retained the fixed H007 cohort but failed its fresh
current-equivalence checks, so it generated no sixteen-replacement study
futures. H007's original feasibility verdict remains intact; its selected
cohort's tight current equivalence did not reproduce under H008's new probes.
H004 remains the confirmed forms contribution, and H005/H006 verdicts remain
unchanged. No H007 job remains running.

Swap 1, 2, 4 or 8 opposite-phase hidden-neuron pairs in both writing
observations. Keep all sites 0–23 and the visible record block fixed. Each
altered packet is an exact writer output and a coordinate permutation of the
source, preserving its weight histogram and norm. Shared base weights remain
fixed. These are larger, structured alterations than H006's four edge flips.

Eight probes define the current-function match; 64 independent probes validate
it. Every dose needs at least 64 matches in 16 networks, ≥95% success in both
variants, and all five current difference intervals inside ±1 percentage
point. All current decisions are sealed before any replacement observation.
If none pass, no study replacements are generated.

When a current match is admissible, eight independent trials each perform one
damaged replacement under the common apparatus. Both variants must retain
their own distinct intended packets exactly, with functional rebuilt bodies
and fresh readers. The mean joint event must reach 80%, its adjusted lower
bound 70%, and both read/write route contrasts must reach 50 points with
positive adjusted lower bounds. The largest passing dose is nominated.
Protected and damaged copying, donor transplant and exact restoration remain
visible. Copying uses less computation.

This uses all 24 already exposed H003 development networks and the source
packets previously extracted and sealed for H006. It does not use H004
confirmation inputs or private artifacts. A positive screen establishes only
one-replacement feasibility; it cannot qualify the failed H005/H006 durability
claim or establish repair superiority. No later study is automatically run.

bash run_python.sh h007/launch.py --mode benchmark --version v1

Run directories are never reused. The launcher verifies cached inputs against
their H006 seals and preserves their H003 provenance receipts. It freezes the
protocol, source, inputs and runtime configuration, runs the original four
fixtures plus six new ones, and audits every current probe and replacement.
The engineering benchmark forces all four doses and all eight trials using
the excluded seed 12900, without making a scientific candidate decision.

The development forecast is the complete benchmark time ×24 with 25% headroom
and 60 seconds. Forecasts above ten minutes detach with a log, PID, frozen
configuration and durable status. Execution follows [RUN_POLICY.md](../../RUN_POLICY.md):
one worker, one numerical thread, all artifacts local, and user-requested
status checks for detached runs.
