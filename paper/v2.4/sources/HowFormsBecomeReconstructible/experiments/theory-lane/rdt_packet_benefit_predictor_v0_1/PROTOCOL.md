**A cheap action-aware repair-benefit predictor: development before new founders.**

The preceding paired pilot is complete and audited, with an unresolved net-benefit result in both noise conditions. All its 63 boundary records, 126 paired outcomes and sixteen acquisition blocks are exposed development data. Thirteen record/regime outcomes differ between repair and control. This calculation uses those labels to challenge one small predictive reduction before paying for new acquisition or futures.

The target is D = Y_H(Rw) − Y_H(w), where R is the unchanged once-only packet completion, both branches receive the declared common future disturbances, and H is eighteen rewrites followed by the fresh terminal recipient. The model is a clipped linear predictor of D from the independent-noise indicator, signed transfer T64(w) and the change T64(Rw) − T64(w). Signed transfer is measured on the normalized graph for64 iterations with the input port clamped; its task-aligned output margin uses the supplied rule and port geometry. The candidate uses no current body, current-expression score or history label. The proposed mechanism is that the action's change in a useful transmission property may identify benefit more directly than risk alone. This is a conventional candidate regression, not an established RDT law.

One weighted ridge fit is used, with unpenalized intercept, training-fold centering/scaling, and penalty1 on the standardized slope coefficients. The fixed strong shrinkage and three-feature limit respond to the small number of independent blocks and rare nonzero outcomes. No penalty grid, outcome-selected bins, feature search or subgroup rescue is allowed in this version. Predictions are clipped to[−1,1]. Whole acquisition blocks are left out together, retaining related founders, histories, recipients and both regimes in one fold. Weights give each block equal weight, each current-expression class half that block, and each noise regime half again. Training weights are normalized inside each fold. Test-block features and labels must not affect scaling or fitting.

Comparators are zero benefit, the training-fold mean benefit separately by noise regime, the same ridge model using noise plus original signed transfer without the proposed-action change, and ridge benefit models using noise plus each existing fixed risk forecast: TT008 ordinary, direct-eight and successor-fixed32. The latter probabilities were frozen before these paired outcomes. All fitted ridge models use the same penalty. The direct and successor versions retain their extra eight and sixty-four native-probe costs per case/regime. The ordinary risk comparator has zero additional full probes beyond shared boundary features, but those boundary measurements and fixed modeling apparatus are not free.

Report held-out-block mean squared paired-difference error in each noise regime, every comparator contrast and all block scores. These are development diagnostics: the family and procedure were chosen after earlier outcomes were known, and overlapping fitted folds do not create independent confirmations. Advance to measuring feasibility of a separate-founder test only if candidate error is strictly below every declared comparator in both noise regimes. Equality fails. This is a conservative spending gate without a claimed effect-size or confidence guarantee. Failure preserves the full candidate and ends this version without tuning or new scientific futures. A pass requires a separate frozen test contract, qualification and runtime benchmark before new-founder acquisition.

Offline action diagnostics use the fixed rule “apply if predicted benefit is strictly positive.” No repair and repairing every case once are shown alongside all benefit models. Existing paired labels permit a development diagnostic value, not a new policy trial. Count applied repairs, full probe reads, dry-run repair calls and total deployment solver calls separately. The candidate must compute a dry-run repair on every packet to calculate its action-response feature, even when it later declines intervention. If selected, reuse that computed packet. This is extra decision work compared with simply repairing all packets; do not conceal it by counting only applied repairs. These resource vectors differ, so the comparison does not qualify a matched-total-budget scheduler or an optimal sequential policy.

Every source input and output commitment is rechecked. Original/repaired packets are matched to the pre-future action seal. Signed transfer is checked with a separate sparse/flat calculation. All folds, coefficients, predictions, score reductions, cost counts and gates receive a separate scalar normal-equation and elimination audit. The qualification includes a known shrinkage solution, test-block contamination, constant-target counterexamples, harms and preservation of dry-run costs. The calculation uses one numerical thread after a host CPU admission check, a five-minute development cap, no new native reads and no automatic successor. The user's preferred one-hour and general six-hour limits remain applicable to any later experiment.
