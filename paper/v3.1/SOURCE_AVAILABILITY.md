# Source availability — v3.1

This source package contains the updated main manuscript, 127 evidence notes and 82 supporting methods. E125–E127 add five completed multiscale development studies: NP002, NL001 and BE006–BE008. BE009 and BE010 contribute frozen designs and passing implementation qualification only; no scientific outcome is selected for them.

All 286 records in the new frozen intake fit the 256 KiB cap and are included byte for byte. The [inventory](source-inventory.json) identifies code, protocols, compact results and retained checks. They are under sources/HowFormsBecomeReconstructible/experiments/multiscale-error-lane/. The scientific source paths and hashes are preserved; some launchers still use their original external run-storage paths. This is an inspectable source snapshot, not a claim of complete portable cohort replay.

Earlier selected evidence remains at its earlier public versioned paths. Large raw arrays, external run archives, source ZIPs and standalone raster illustrations are omitted. The [figure map](FIGURE_MAP.md) retains the 20 main and five supporting figure identities and original hashes; available small SVG counterparts remain linked. The two revised inspiration infographics are not silently replaced by older images. Their complete raster previews will appear in the rebuilt v3.1 PDFs.

The existing local v3.1 PDFs predate the multiscale intake and are deliberately not copied as current. The latest matching public rendered pair is [v2.5](../v2.5/README.md). A v3.1 build, visual review, PDF hashes and SI page index remain pending. Version 2.5 has been deposited on Zenodo according to the author; this v3.1 working source package is not a new deposit and no DOI is invented.

This export does not rerun simulations, fits, raw-shard analyses or original uncertainty calculations. Existing missing forecast/outcome and timing-panel exports remain documented in the [v2.5 availability record](../v2.5/SOURCE_AVAILABILITY.md). Development does not become confirmation through packaging. Public installation is separate from the author's commit and push.
