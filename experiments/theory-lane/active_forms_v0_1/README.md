# Active forms: body-source replication and extension

**11 October 2026 — DRAFT_NOT_REGISTERED.** Proposed after the author's request
to strengthen the preprint's active-form synthesis and consider replications in
the theory lanes. This folder contains a test design, not a new result, frozen
prediction, implementation or compute launch.

The first question is concrete: **can surviving body organization write a
distinction into a successor record when the incoming record no longer tells
the two histories apart?**

- [Design](DESIGN.md): reproduce the existing spatial-organization comparison,
  then separate body-supplied content from amplification of residual record
  information.
- [Draft prediction card](PREDICTION_DRAFT.json): explicit unfilled quantitative
  commitments and information boundaries.
- [Evaluator intake](../../theory-tests-lane/reviews/active_forms_v0_1/INTAKE.md):
  independent implementation and verification requirements.

This maps to **RDT-P05 in the original charter**. It does not rename or change
the existing `p05_*` functional-network repair studies, their protocols, or the
TT010–TT015 evidence. The proposed study label **AF01** is a design identifier,
not a reserved TT number or a completed experiment.

The current paper uses existing results in [section 4.7](../../../MANUSCRIPT.md#active-forms).
The stronger question of a body rebuilding its own reader/writer machinery
belongs to RDT-P07 and remains a later hypothesis. Existing Wagner mutation
attenuation is a comparator, not an implementation of that stronger capacity.
