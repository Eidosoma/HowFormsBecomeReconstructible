successor record when they start repair with exactly the same incoming record?**

## Why this is a new intervention

D073/D074 establish a bounded repair benefit and a contribution of spatial
organization. D078–D080 already substitute actual donor bodies, reverse donor
assignments and separate values from rank layout. This study does not repeat
those donor swaps: it first removes the intended within-pair distinction from
the incoming record by giving both histories identical bytes, and resets both
R and the activity average identically. The old protocols initialized the
average from V. That change must remain explicit.
