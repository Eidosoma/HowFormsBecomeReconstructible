# Proposed shared frozen comparison — not a launched confirmation

TT051 provides a fixed regularized cheap comparator and feature-only prediction
interface for theory-lane's next probe-depth study. Development is exposed;
the resulting MODELS.json is not evidence of prospective superiority. Before
untouched-source evaluation, a new theory-lane protocol or dated prospective
amendment must bind both its complete design and TT051's MODEL_FREEZE.json.
Existing frozen studies and their original claims remain unchanged.

1. Use one shared acquisition/enrollment cohort, one set of probe banks and one
   set of terminal future banks for all predictors. Retain the declared initial
   expression classes and all enrolled cases, including failed continuations.
   No source or probe is selected by a favorable forecast or future result.
2. Exclude this panel's source blocks 0–7 and all other source populations whose
   outcomes informed model/design choices. At minimum, all 80 previously exposed
   fresh-equal-read sources, TT008's 8800000–8800063 test sources and E107 are not
   untouched. Numeric IDs alone are insufficient: bind acquisition namespaces,
   source packet hashes and the source-exposure registry. Related histories and
   descendant packets stay in the same independent source unit.
3. Bind the exact acquisition law, enrollment rule, continuation injury/noise,
   writer schedule, numerical channel, target horizon and terminal read. The
   fitted model targets the shared g14→18 exact rewrites→fresh g33 contract.
   Different horizons, source families or continuing tolerance rules are
   explicit transport tests, not the same confirmation.
4. Keep the fixed zero-probe cheap model, class/history baseline, B11 boundary
   model and original TT008 reference. Probe-augmented competitors should get
   the same cheap information, plus their own explicitly priced probe features.
   Fit those augmented models on development blocks only and freeze their
   calibration, coefficients, probe depths and aggregation before evaluation.
   This interface does not authorize silently refitting an old frozen model.
5. Freeze the shared source count, independent-block inference, practical Brier
   criterion, calibration criterion and stopping rule before future outcomes.
   Use a precision justification that accounts for source grouping and
   development uncertainty; do not select a threshold from TT008/E107 effects
   or from whichever new method wins. The current package reserves no cohort
   or effect-size-based sample size: theory-lane owns that shared design.
6. Generate source boundaries and permitted probe data, then seal all models'
   predictions for the whole cohort before any target continuation. Keep probe
   and terminal futures independent, pair terminal futures across predictors,
   and record whether deeper probes are nested or independent. Retain loss,
   calibration, current-class and condition results even when they conflict.
7. Score paired source-block Brier differences, log loss and calibration against
   every predeclared reference. Report native read/write counts, 64-step linear
   diagnostics, feature extraction, fitting/calibration, inference, storage and
   wall/CPU costs separately. No equality of native-read budgets implies equality
   of all computation. Any claim of probe value is conditional on those budgets.

Parent/grandparent prediction is a separate secondary information comparison.
It is not a gate for declaring the record non-Markov. The reset-contract audit
is also a separate result and needs no duplicate long simulation campaign.

The confirmation is frozen only when the receiving lane binds the actual
cohort, endpoints, probe-depth grid, all trained artifacts and statistical
decision rules. A handoff file alone is not evidence that integration or
prospective evaluation has occurred.
