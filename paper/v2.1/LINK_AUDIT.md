# v2.1 exported-link audit

Every repository URL in the main and supporting PDF annotations was checked against the prepared package or an existing local Git object, including evidence anchors and referenced SI page numbers. No malformed commit/path construction or missing destination was found. This is a local package audit, not a claim of live HTTP availability.

External literature URLs were not rechecked online in this packaging pass. Both PDFs offer reciprocal navigation and the [methods index](METHODS_INDEX.md) gives all 51 SI page numbers.

Checked 527 annotations representing 276 unique URLs.
