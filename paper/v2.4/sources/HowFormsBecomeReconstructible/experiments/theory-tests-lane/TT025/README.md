# TT025: paired receiving effects of saved rewrites

TT025 measures whether replacing an incoming record with the actual record
written from it changes reconstruction in the same fresh receiving conditions.
It follows TT024's [saved-change diagnostic](../TT024/SERIAL_CHANGE_INTERPRETATION.md),
which found shrinking intended-versus-competing pattern margins but could not
measure the functional effect of individual rewrites.

The [protocol](PROTOCOL.md) retains all four exposed blocks, both record
families, four historical futures, four policies and eight cycles. Each saved
version receives four new recipient draws, paired across versions and policies.
The initial packet and byte-identical preservation versions share verified
assays. The fixed schedule is 3,200 native batches, 51,200 individual receiving
evaluations and independent replay, yielding 65,536 paired cycle/draw contrasts.
The population still comprises only four blocks.

The primary descriptive endpoint is informative corrected writing's
final-minus-initial receiving credit. All cycle effects, gains, harms, block
effects, messages and injury/body-status strata remain. Neither geometry nor
old body performance selects cases. There is no significance gate or claim of
fresh-population confirmation, and the assay creates no new repair trajectory.

Only the 2,048-byte record enters the physical reader. Body state and task
labels are rejected at that boundary; labels enter later scoring. Qualification
passes 23 checks, including exact native-adapter equivalence, independent
physical replay, serial/two-worker equivalence, malformed-input rejection,
preservation, mixed outcomes with three-way ties, and paired telescoping.
